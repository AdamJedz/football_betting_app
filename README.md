# Football Betting App

A Python application for football betting analysis and management.

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/AdamJedz/football_betting_app.git
   cd football_betting_app
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS/Linux
   source .venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
